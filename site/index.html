A menu bar app for Claude Code

Four sessions are waiting on you. Clear them in a minute.

Vassy sits in your Mac’s menu bar and watches every Claude Code session you have open. When one stops and needs you, it boils the whole scrollback down to one question and a recommendation, then types your answer into the right Terminal tab.

How it works

Three small parts, all on your Mac.

1

A hook notices the stop

Vassy registers a tiny Claude Code hook. Whenever a session finishes a turn or asks for permission, the hook writes one small file. Nothing polls, nothing scrapes your screen.

# ~/.claude/settings.json
Stop · Notification
UserPromptSubmit · SessionEnd
  → ~/.vassy/hook
2

Your own Claude sums it up

The app hands the tail of the transcript to the claude CLI you already have, on the small fast model. Back comes a title, the open question, a recommendation and up to three ready-made answers.

claude -p --model haiku
  --tools "" --strict-mcp-config
  → { "question": "…", "actions": […] }
3

You answer, Vassy types

Press a key. Vassy finds the Terminal tab that session lives in, types your reply and hits Return. You never switch windows unless you want to.

you      ⌘1
vassy    → Terminal · ttys004
claude   working…

What you get

Built for the moment between two prompts.

⌘1⌘2⌘3⌘↵

One key per answer

Every waiting session comes with up to three complete replies, written the way you would write them. The first one follows the recommendation. Before you send, Vassy shows the exact text that will be typed.

“Fix it. It’s a six-line change in the expiry check.”

A recommendation, not a recap

You get where things stand, the one thing Claude needs, and what to do about it.

Run on production⌘1

Production is marked

Answers that deploy, merge to main or touch live data carry a warning mark. Sessions that already shipped something wear a LIVE badge.

Say it or type it

The reply field has focus the moment the panel opens, so any dictation tool works. Talk, hit ⌘↵, done.

A queue, not a dashboard

Open it from anywhere. The session that has waited longest comes first. Push one to the back, jump into its tab when you need the full picture, or hide it for good. A notification tells you when a new one starts waiting.

Privacy

Your code goes nowhere new.

  • 01

    No server, no account, no analytics

    Vassy is a single local app. It has no backend and never phones home.

  • 02

    Summaries run through your Claude Code

    The only place a transcript is sent is the Claude Code CLI that produced it, on the login you already use.

  • 03

    The summarizer can read, nothing else

    It runs with tools and MCP servers switched off, and treats the transcript as data rather than instructions.

  • 04

    Everything stays in one folder

    Queue state lives in ~/.vassy. Delete the folder and it is gone.

Install

Download, drag, done.

Vassy is free. It is signed and notarized by Apple, so it opens like any other Mac app.

  • macOS 15 or later, with Terminal.app
  • Claude Code, signed in
  • Codex CLI works too; that support is new and still in beta

  2. 2

    Unzip, then drag Vassy into your Applications folder.

  3. 3

    Open it and pick your agents

    Vassy adds its hook to the agents you choose, after saving a backup of each config file. Then press ⌥⌘C from anywhere.
